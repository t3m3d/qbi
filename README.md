# QBI (Quantum Binary Interface)

Quantum Binary Interface -- Krypton-Lang Quantum Programming Extension.

The canonical specification lives in the Krypton monorepo at
`krypton/docs/design/QBI.md`. The ABI it extends is specified in
`krypton/docs/design/KBI.md`.

This repository is reserved for QBI implementation work as it lands; it
deliberately carries no spec copies so the monorepo remains the single
source of truth.
